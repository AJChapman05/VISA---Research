---
name: michael-burry-10k
description: Screen a company with Michael Burry-style cash-flow and leverage checks using shared printed SEC EDGAR 10-K facts.
---

Use only the shared printed SEC EDGAR 10-K facts; never estimate or introduce a new number. Operating cash flow must be at least net income in every year. Latest liabilities must be no more than twice latest equity. Zero, negative, or missing equity is `not known`, and any other missing required data is `not known`. Write a memo using only values printed by the program.
